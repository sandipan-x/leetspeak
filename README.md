# LeetSpeak

Free leetspeak translator: convert text to 1337 with adjustable intensity, decode leet back to plain text, and copy gamer-ready styles instantly.

## Features
- intensity slider (light / medium / full)
- reverse decoder (leet to plain text)
- preset styles with one-click copy
